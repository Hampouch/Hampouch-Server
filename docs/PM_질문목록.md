# PM 확인 질문 목록 (햄포치 서버)

> 📌 **이 문서는 PR 리뷰 대상이 아닙니다** — PM에게 물을 질문을 서버 파트가 모아 두는 장부입니다. 폴더 성격은 `docs/README.md` 참고.
>
> 규칙: 질문 문장만 적는다(배경·현행 동작·후보 답은 `_claude/질문배경.md` 같은 번호에). 답이 나온 질문은 지우고 1부터 재정렬.

1. **월급날 주기 모드**
   - 온보딩 예산 입력은 하루당 목표인가, 기간 총액인가? (0714 전체회의 확정과 현행 온보딩2 시안이 서로 다름)
   - 주기가 새로 시작될 때마다 그 주기의 총예산은 어떻게 정해지나 — 하루 한도 × 그 주기 일수인가, 직전 총액 그대로인가?
   - 가입일~첫 월급날의 부분 첫 주기도 같은 계산인가?
   - 주기는 언제까지 반복되나 — 유저가 끄기 전까지 무한인가? 해지는 어떻게 하나?

2. **기간 만료 후 '챌린지 최종 종료'(finalize)**
   - 만료 후 "지출 수정 유예 → '챌린지 종료' 버튼으로 확정·잠금" 흐름이 확정인가?
   - 유예 기간의 상한은? 종료 버튼을 계속 안 누르면 어떻게 되나?
   - 잠금 후에는 지출 수정도 막히는 건가?

3. **경고 카드** — "카드는 위험 홈에서만 노출"이 실제 디자인 의도인가?

4. **예산 하한·상한** — 온보딩에 예산 최소 입력값이 있나? 하루 한도가 0원이 되는 조합(저예산·장기간)을 서버가 막아야 하나? 예산 0원의 "무지출 챌린지"는 지원할 의도가 있는 기능인가?
   - **예산·지출 입력의 상한은 얼마인가?** (기간은 0714에 100일로 상한이 정해졌는데 금액은 상한이 없음 — 화면에 입력 자릿수 제한이 있나?)

5. **경계값 소속** — 사용률이 정확히 30%·70%일 때 어느 구간인가?

6. **실패 챌린지의 "연속 달성" 표시** — 기간 중 최장 연속인가, 종료 시점의 마지막 연속인가?

7. **성공/실패 판정 기준** — 하루라도 한도를 넘긴 날이 있으면 실패인가, 기간 총지출이 예산만 안 넘으면 성공인가?

8. **결과 화면 도장 달력** — 챌린지가 두 달에 걸치면 달 넘김 UI가 생기나?

9. **추천 미니 카탈로그**
   - 확정된 실물 리스트를 서버로 전달해 줄 수 있나?
   - "노출은 랜덤"이 전체를 무작위 순서로 반환인가, 무작위 N개 추출인가? (N=?)

10. **미니 챌린지**
    - 같은 추천을 이미 진행 중일 때 추가를 막는 것(409)이 확정 사양인가?
    - 커스텀 제목의 최대 길이는?
    - 그날 조회에 미래 날짜를 허용하나?
    - [안드 확인] 조회일이 아직 미완료면 전날까지의 연속을 보여주는 게 맞나? 연속이 끊긴 다음날의 표시값은?

11. **배틀 무효 규칙의 본챌린지 이식 — 잔여 정의** (0715 PM 확정분: 이식 O · 알림 로직 공용 + 멘트만 변경 · 챌린지 무효 화면 신설)
    - 무효는 **연속 3일**부터인데, 그 전인 **1~2일 미기록은 계속 "0원 = 그날 성공"**인가? (0714 "미입력일=0원=성공"이 3일 미만 구간에선 그대로 사는지 — 홈 현황·결과 집계가 여기서 갈림)
    - "7일 이하 배틀 예외"를 본챌린지에도 그대로 적용하면 **기간 프리셋 3일·7일과 직접 입력 1~7일이 규칙 밖**이 된다(그 챌린지들은 전일 미기록이어도 성공). 의도한 것인가?
    - 무효된 챌린지는 **지난 챌린지 기록 리스트·결과 화면**에 남나? 실패와 구분해서 표기하나, 아예 안 남나?

12. **지난 챌린지 기록 카드(마이페이지)** — 0717 피그마 실측에서 발견(배경 12번)
    - [안드 확인] 리스트 맨 위 "진행중" 카드는 홈 현황(`current`) 재사용으로 안드가 그리나, 히스토리 응답에 진행 중 포함을 원하나? (현행 서버 = 종료된 것만)
    - [안드 확인] 카드 칩 "n/14"의 n은 무엇인가 — 성공 일수인가, 경과 일수인가?
    - [안드 확인] 카드의 "하루 한도 N원"은 서버가 응답에 실어줘야 하나? (현행 응답엔 없음)

13. **포기한 챌린지의 결과 집계 구간** — 0717 중도 포기(#3) 구현 중 발견(배경 13번)
    - 중도 포기한 챌린지의 결과 화면·지난 챌린지 카드에서 "성공한 날"과 "총 절약"은 어디까지 세나 — 포기한 날까지인가, 원래 목표 기간 전체인가? (미입력일=0원=성공 규칙을 기간 전체에 그대로 적용하면, 30일 챌린지를 2일차에 포기해도 실패 카드에 "성공 30일·절약 전액"이 표시됨)
    - 같은 뿌리: 지난 챌린지 리스트의 "최근 종료 순" 정렬에서 포기 챌린지의 자리는 실제 포기한 날인가, 원래 목표 종료일인가? (현행 서버는 포기 시각을 저장하지 않아 원래 종료일 자리 — 긴 챌린지를 일찍 포기하면 그 뒤 완주한 짧은 챌린지보다 위에 뜰 수 있음)
    - 첫 항목의 답은 휴식기 홈의 "보관 중인 내 기록"(#8)에도 그대로 적용하면 되나? (같은 집계 규칙 공유 — 배경 13번)

14. **중도 포기 진입점·경계** — 0717 피그마 전수 실측 + #3 구현 중 발견(배경 14번)
    - [디자인 확인] 그만두기(중도 포기) 화면·버튼이 스크린디자인·와이어프레임 어디에도 없다 — 진입점이 어느 화면에 생기나? (0707 "그만두면 실패" 결정만 있고 시안 없음)
    - 기간이 이미 끝났는데 결과 화면을 안 열어 미확정으로 남은 챌린지에 그만두기 요청이 오면? (현행 서버 = 기록 기준 결과로 먼저 확정하고 "이미 종료" 409 — 잠정)
    - 포기한 챌린지의 기간 내 지출 수정 허용은 0711 "종료 후 자유 수정"에 포함되는 해석이 맞나? (현행 서버 = 수정 허용, 단 결과 재계산에서만 제외)

15. **휴식 잠정 결정 8건** — 0718 휴식(#8) 구현 중 자체 결정 + 0719 추가(배경 15번)
    - 쉬는 일수(restDays)·연장 일수(extendDays)에 기획 상한이 있나? (현행 서버 = 3650일 기술 상한만 — 정책값 아님)
    - "내일부터 복귀"를 골라둔 당일에 "조금 더 쉴게요"를 고르면 내일 복귀 예약은 취소하고 휴식을 잇는 게 맞나? (현행 서버 = 예약 취소 + 예정일 연장 — 취소 안 하면 연장했는데 내일 휴식이 끝나는 모순)
    - 휴식기 홈 "보관 중인 내 기록"의 "누적 절약 금액"·"최고 연속 달성"은 무엇을 집계한 값인가 — 직전에 끝난 챌린지 하나의 결과인가(현행 서버 — 와이어프레임 숫자가 직전 성공 결과 화면과 일치해 그렇게 구현), 역대 챌린지 전체의 누계(절약 합산·역대 최고 연속)인가? 역대 누계라면 실패·중도 포기한 챌린지의 몫도 합산에 넣나?
    - 종료된 챌린지가 하나도 없는 유저가 휴식을 시작하면 휴식기 홈의 "보관 중인 내 기록"은 0원·0일로 내려도 되나? (온보딩 건너뛰기로 챌린지 없이 시작한 유저가 후보 — 서버는 이 조합을 막지 않음) [디자인·안드 확인] 챌린지가 하나도 없는 유저에게 휴식 시작 진입점이 보이는 화면이 있나?
    - 복귀 팝업의 "내일부터 할게요"는 내일 종료를 확정하는 응답인가, 결정을 내일로 미루는 것(다음날 팝업 재노출)인가? (현행 서버 = 내일 종료 확정. 미루기로 읽으면 "조금 더 쉴게요" 1일 연장과 동일해져 선택지가 겹침 — 대신 확정이면 다음날 마음 바꿔 더 쉴 경로가 없음) [안드 확인] 누른 다음 날 첫 화면은 챌린지 생성 유도인가, 팝업 재노출인가?
    - [디자인·안드 확인] "조금 더 쉴게요"를 누르면 연장 일수를 고르는 화면이 이어지나? (0718 스크린디자인 실측: 복귀 팝업만 있고 후속 일수 선택 시안이 없음 — 현행 서버의 "기간 재선택(extendDays)" 계약은 자체 결정. 선택 화면이 없다면 이 버튼은 서버 호출 없는 팝업 닫기(다음 실행 때 재노출)로도 성립하는데, 그 경우 복귀 API의 EXTEND 선택지 사용 여부를 재확인해야 함)
    - [디자인·PM 확인] 휴식 시작 화면("잠깐 쉬어갈까요?")의 문구 — "챌린지만 멈출 뿐"·"취소하고 챌린지 계속할래요" — 가 진행 중 챌린지에서의 휴식 진입을 시사한다. 진입점 = 결과 화면뿐(0707 화면 확정, 진행 중이면 409)이 여전히 맞나, 아니면 진행 중 진입으로 바뀐 건가? (바뀐 거라면 "멈춘" 챌린지의 처리 — 포기 FAIL인가 별도 상태인가 — 까지 정의 필요. 현행 서버 = 진행 중이면 409)
    - [디자인·안드 확인] 휴식기 홈의 "다시 챌린지 시작하기"를 누르면 어디로 가나 — 새 챌린지 설계 화면으로 바로 가나, 복귀 팝업("다시 돌아오신 걸 환영해요")을 거치나? (와이어프레임에서 이 버튼만 연결 화살표·주석이 없고, 복귀 팝업 프레임 제목은 "휴식기 이후 팝업"이라 예정일 도래 트리거로 읽힘 — 서버는 어느 쪽이든 수정 없이 대응)
