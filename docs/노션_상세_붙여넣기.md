▼▼▼▼▼▼▼▼▼▼  복사 시작  ·  붙여넣을 곳 = [challenge 1 — 챌린지 생성 · POST /api/challenges] 행  ▼▼▼▼▼▼▼▼▼▼

## Request
```json
{
  "durationDays": 30,
  "budgetTotal": 100000,
  "startDate": "2026-06-23",
  "resetByPayday": true,
  "paydayDay": 25,
  "weakCategories": ["카페", "배달", "편의점"]
}
```

## Response (201 Created · Location: /api/challenges/{id})
```json
{
  "code": "SUCCESS",
  "message": "요청이 성공했습니다.",
  "data": {
    "challengeId": 1,
    "dailyLimit": 3333,
    "startDate": "2026-06-23",
    "endDate": "2026-07-22",
    "status": "IN_PROGRESS"
  }
}
```

## Error Response
- 필드 누락·형식·범위 위반(durationDays 1~100 — 상한 100일은 0714 전체회의 확정), resetByPayday=true인데 paydayDay 없음 (400)
```json
{ "code": "VALIDATION_ERROR", "message": "입력값이 올바르지 않습니다.", "status": 400,
  "fieldErrors": { "durationDays": "100 이하여야 합니다." } }
```
- 이미 진행 중(IN_PROGRESS) 챌린지 존재 — 동시 1개 가정 (409)
```json
{ "code": "CHALLENGE_ALREADY_IN_PROGRESS", "message": "이미 진행 중인 챌린지가 있습니다.", "status": 409 }
```
- 토큰 없음/유효하지 않음 (401)

▼▼▼▼▼▼▼▼▼▼  복사 시작  ·  붙여넣을 곳 = [challenge 2 — 진행 중 챌린지 + 현황 · GET /api/challenges/current] 행  ▼▼▼▼▼▼▼▼▼▼

## Request
요청 바디 없음 (인증 헤더만). 진행 중이면 challenge/progress/consumption/warningCards/adjustment 5블록을 항상 함께 반환.

## Response (200 OK · 진행 중)
```json
{
  "code": "SUCCESS",
  "message": "요청이 성공했습니다.",
  "data": {
    "challenge": {
      "id": 1, "durationDays": 30, "startDate": "2026-06-23", "endDate": "2026-07-22",
      "budgetTotal": 100000, "dailyLimit": 3333, "status": "IN_PROGRESS"
    },
    "progress": {
      "elapsedDays": 5, "remainingDays": 25,
      "successDays": 4, "overDays": 1, "currentStreak": 2, "savedAmountSoFar": 4200
    },
    "consumption": {
      "todaySpent": 2000, "todayRemaining": 1333, "dailyLimit": 3333,
      "usageRate": 0.6, "character": "NORMAL", "alertLevel": "CAUTION"
    },
    "warningCards": [],
    "adjustment": { "usedCount": 0, "maxCount": 2 }
  }
}
```

## Response (200 OK · 휴식 중)
```json
{
  "code": "SUCCESS",
  "message": "요청이 성공했습니다.",
  "data": {
    "challenge": null,
    "rest": { "restStartDate": "2026-07-06", "plannedResumeDate": "2026-07-13" },
    "keptRecords": { "savedAmount": 68200, "maxStreak": 14 }
  }
}
```

## Error Response
- 진행 중 챌린지 없음(휴식도 없음) (404)
```json
{ "code": "NO_ACTIVE_CHALLENGE", "message": "진행 중인 챌린지가 없습니다.", "status": 404 }
```
- 인증 실패 (401)

> 참고: character = FULL/NORMAL/SKINNY, alertLevel = NONE/CAUTION/DANGER — 경계 둘 다 30/70(0714 통일, 필드는 분리 유지). progress는 미입력일=0원=성공으로 채워 집계(0714 — 결과 화면과 동일 규칙, 오늘은 기록 시에만 포함). warningCards는 현재 GOAL_TOO_TIGHT(3일 연속 한도 초과)만 구현 — 오늘 사용률과 무관하게 발동, 미기록일이 지나가면 연속이 끊겨 사라짐. adjustment.usedCount는 조정 구현 전 0 고정. 위젯도 이 API 재사용 예정.

when = NOW(지금 바로) / TOMORROW(내일부터) / EXTEND(조금 더 쉴게요). EXTEND면 extendDays(≥1) 필수.
```json
{ "when": "EXTEND", "extendDays": 7 }
```

## Response (200 OK)
```json
{
  "code": "SUCCESS",
  "message": "요청이 성공했습니다.",
  "data": { "restId": 3, "resumeDate": "2026-07-07" }
}
```
EXTEND면 data = { "restId": 3, "plannedResumeDate": "2026-07-20" }

## Error Response
- when 오류 · EXTEND인데 extendDays 없음 (400)
```json

```
- 휴식 중 아님 (404)
```json
{ "code": "REST_NOT_ACTIVE", "message": "휴식 중이 아닙니다.", "status": 404 }
```
- 인증 실패 (401)
