# 다음 챌린지 추천 API 명세

> ⚠️ **초안(미확정) — 리뷰 대상 아님.** 서버 파트 작업 문서의 백업이며, 구현하면서 확정한 뒤 docs/ 루트로 옮겨 그 구현 PR에 포함한다. 팀이 보는 명세는 노션 "API 설계"뿐.
> 대응 화면: 새 챌린지 설계(성공 후/실패 후) — 결과·휴식기에서 진입, 추천이 프리필됨. 생성 자체는 기존 `POST /challenges`(2026-07-07 확정).
> 상태: 초안 ⚠️ · 구현: ⏳ 미구현(후속 이슈) · 공통 규약은 `API명세_본챌린지.md` §0.

## `GET /api/challenges/recommendation` — 다음 챌린지 추천 🔒 ⚠️

**응답 `200 OK`** (직전 종료 챌린지 기반)

```json
{
  "lastChallenge": { "durationDays": 30, "status": "SUCCESS",
    "budgetTotal": 400000, "actualSpent": 340000,
    "tags": ["60,000원 아낌", "목표 대비 15%↓", "28일 기록 유지"] },
  "recommendation": {
    "durationDays": 30, "budgetTotal": 330000, "dailyLimit": 11000,
    "focusCategories": ["배달", "카페"],
    "message": "목표보다 60,000원이나 아꼈어요. 이 흐름을 이어가되 이번엔 살짝 더 타이트하게 가봐요. …"
  }
}
```

- ⚠️ **수치 산정 기준 미정** — 0630 "±10%"와 화면 수치가 정확히 안 맞음(실패 시 기간 단축·집중 카테고리 축소 포함). 문구(message) 생성 방식은 **룰 기반 확정(0711 PM — AI 안 씀)**, 수치 % 공식만 기획 확인 대기. 확정 전엔 시드/룰 스텁.
- 실패 태그("스트레스 45%", "주말·배달 집중")는 령준 지출의 감정·요일 집계 의존(연동 계약).

**에러**: 401 / 404(종료된 챌린지 없음 — 첫 챌린지는 온보딩 직접 설정).
