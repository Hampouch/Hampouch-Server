## `PUT /api/challenges/{id}/focus-categories` — 집중 카테고리 수정 🔒 ⚠️

**요청 바디**: `{ "categories": ["배달", "카페"] }` — **전체 교체**(PUT 멱등). 검증: 기본 7종 + 자유 문자열(직접추가).

**응답 `200 OK`**: `{ "challengeId": 1, "categories": ["배달", "카페"] }`

**에러**: 400(빈 배열 허용 여부 ⚠️잠정: 허용) / 401 / 403 / 404 / 409(⚠️잠정 — IN_PROGRESS 아닐 때).
